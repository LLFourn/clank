# Remove wait generation, claim, and turn-end state

## Goal

Delete the per-agent `wait.gen`, `wait.claim`, and `turn.end` mechanisms, including their locks, compatibility readers, CLI arguments, diagnostics, and tests that exist only for them. A Stop hook and a session-bound `clank wait` should use the agent's current `config.json` binding to decide whether they may emit work. A terminal-launched wait without a delivery session may still be used directly, but cannot prove a hook has a waker. Concurrent waits for one label are allowed. Do not replace these files with another per-agent incarnation counter, admission lease, or turn-end stamp.

The harness permits only one holder of a session at a time. An older background wait may nevertheless survive a session handoff. Treat it as another waiter: it must not block the new wait, consume an explicitly acknowledged event, or run a side effect twice. A wake printed to an old, detached task is harmless only when the new wait can independently obtain the same pending work. No proof of current-harness child lifetime is required to remove the counter once that condition holds.

## Work

1. **Remove wait-invoked hooks.** Delete `hooks.master_work`, `hooks.reviewer_work`, `hooks.plan_finalized`, and `hooks.idle` from the configuration and CLI surface, their execution in `clank wait`, generated documentation, and associated tests. They are all null in this repo. Keep `hooks.blocked`, which belongs to `clank block create`.

2. **Put PR draft notifications in the event inbox.** Continue reporting a new pending-review comment, edits, deletions, and the draft going away. Record each observed change in the ordinary per-agent event log before presenting it; expose it through `clank events list/show/ack` with a selector. Unacked changes must reappear on later waits, and printing must never acknowledge them. Update the PR review skill and generated instructions: reread the draft, do not reply to an operator edit, then explicitly ack the event. Keep the per-review-run snapshot needed to detect GitHub edits, but delete its `undelivered` queue and `mark_drafts_delivered` path. Give the observer a per-run ingest lease; other waits tail the log. Make log append and snapshot advance retry-safe across a crash, and prevent a late old-run observation or ack from affecting a new review run. Cover new comments, edits, restart, finish, explicit ack, and concurrent waits.

3. **Remove wait admission and claims.** Delete `wait.claim` publication, its lock, the one-slot admission/wait-for-predecessor path, `WaitAlreadyParked`, the `wait_claim` module, and the registration `--tag` used to match a background task to a claim. A normal wait may run alongside another wait for the same agent. Stop must not suppress its own continuation merely because the harness lists a background `clank wait`; when auto mode calls for a wait, the hook owns its wait. Preserve the distinct attended-task path, whose completion is the agent's wake. Keep the hook-owned wait's owner pipe so that child exits with its hook. Remove the claim-dependent doctor, status, and TUI checks. Audit edge-triggered wait items such as finished-plan and ad-hoc-settled notices: if an older wait can be their only observer, make them replayable to a later wait or retire the obsolete notice.

4. **Remove the generation fence.** Delete all `wait.gen` reads and mints at bind, release, SessionStart, Stop, wait, attendance timer, status, and web. At each work-output or turn-decision boundary, check that the current config still binds the expected label, tool, and session; an unreadable or changed binding cannot authorize output. Pass the actual hook-input session to a hook-owned child instead of trusting the long-lived runner's inherited environment. Keep checks late enough to reject a wait from a different session after rebind or release. A repeated SessionStart for the *same* session does not invalidate its existing waits. Remove `--expected-generation` and generation-bearing legacy `wait.holder` handling. Verify two same-session waits can coexist and each see pending work; cross-session stale output is rejected.

5. **Remove turn-end recording and its dependent presentation.** Delete `turn.end`, `TurnEnd`, `TurnLeft` where used only to stamp that file, and the Stop hook's initial/final stamp writes. The doctor `wake:` check and TUI `unreachable_since` indicator infer an abandoned agent from that stamp and the claim; retire those claims rather than replacing them with another persisted turn record. Remove the web `ended`/working inference derived from `turn.end`, or show unknown when its remaining live data cannot support an answer. Preserve independently justified attended-task displays; retire parked-hook status if it depends on the legacy holder. Adjust status fingerprints and wire fixtures accordingly.

6. **Migrate and verify.** New binaries must ignore old `wait.gen`, `wait.claim`, `wait.claim.lock`, `turn.end`, and legacy holder files, and stop creating them. Remove stale copies from this repo only after installing the new binary; old in-flight binaries may still write them until they exit. Test Stop and SessionStart with same-session resume, cross-session rebind/release, a listed completed/background wait, hook owner death, and a concurrently armed new wait. Test ordinary gate work and unacked GitHub, command, and draft events with two waits; neither may silently take the other's delivery. Build and install the Clank binary used by the configured hooks, then smoke the installed Stop path and current-repo migration. Search for remaining file/flag references outside historical plan text before finishing.

## Scope and acceptance

This is one plan because the order matters: side-effect removal and acked draft events make concurrent waits safe; only then remove admission and generation; the turn-end diagnostics can be retired with their inputs. Preserve the existing review gate, event acknowledgment, attended work, and session binding semantics. Completion means no production path reads, writes, or requires the three files; two waits can coexist without suppressing a Stop continuation; and installed hooks run the new binary. The old reachability warning and web ended indicator are intentionally retired with `turn.end`.
