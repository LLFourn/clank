Chapter 2

Getting started

Install clank, wire it into your agent CLIs, give a repo a roster of two agents, and open the team.

What you need

  • git and a Rust toolchain, to build clank.
  • zellij, the terminal workspace clank open lays the team out in.
  • At least one agent CLI: Claude Code, Codex CLI, Grok CLI or opencode. Two different ones make a better team, because each reviews the other.

Install

git clone https://github.com/LLFourn/clank
cd clank
cargo install --path crates/cli --locked

That puts two programs on your $PATH: clank, and clank-web-cloudflare, the host process the remote starts. Keep --locked, so cargo builds against the committed Cargo.lock instead of re-resolving every dependency.

Wire it into your agents

clank setup
clank doctor

clank setup installs, at user level:

  • the role skills clank-master and clank-reviewer, plus clank-github, for each tool;
  • clank’s Stop and SessionStart hooks, merged into Claude Code’s settings.json and Codex’s hooks.json;
  • Grok’s native hooks, in ~/.grok/hooks/clank.json;
  • the opencode plugin, which binds the session and carries its work loop.

The hooks are how an agent gets woken, and the skills are how it learns its job. Run clank setup again after every upgrade. clank setup --dry-run shows what would change first, and clank setup --force overwrites skill files you have edited.

clank doctor checks the repo, your user-level install and the current session, and prints OK, WARN or FAIL with what to do about each. It exits non-zero on any FAIL. It is the first thing to run whenever something seems off.

Give a repo a roster

cd your-project
clank init
clank agent add alice --tool claude
clank agent add bob --tool codex

clank init creates .clank/, with its plans/ directory and a managed .gitignore. It also installs a git post-rewrite hook, so verdicts follow their commits through a rebase or an amend.

The first agent you add becomes the master, because the roster has none yet. Each later one becomes a reviewer of every commit. To choose a different tier, say so:

clank agent add carol --tool grok --review gate
clank agent list

The tiers are explained in Group coding. A label is just a name. Use something short, because you will type it.

Open the team

clank open

This is the step that makes the agents exist. Outside zellij, it starts a session for the repo. Inside one, it adds a tab. Either way you get the master on the large pane, the reviewers stacked beside it, and a clank tui pane. Each agent pane runs clank agent start label, which starts the agent’s CLI in the repo, or resumes its session if it has one.

Each pane starts its tool with its label in the environment, and clank’s SessionStart hook binds that label to the new session. There is nothing to type. Only a session you start yourself, outside clank open, needs binding by hand:

clank as label

Inside the session, move between panes with Alt+h/j/k/l. clank leaves Alt with the arrow keys to the agents, because Codex uses Alt+↑ to edit its last message.

If the repo is already open in some zellij session on this machine, clank open tells you where and opens nothing, rather than starting a second copy of every agent.

Check it

clank status
clank doctor

clank status shows HEAD, the active plan and where its review stands, and the roster. clank agent list adds each agent’s binding. When every agent is bound and doctor is clean, the team is ready for its first plan.
