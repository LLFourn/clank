clank team agent

Your library of agent descriptions, which rosters and teams copy

A description is a tool and its launch, with no role: a repo's roster gives it one when clank agent add <name> copies it.

Usage

clank team agent <COMMAND>

Commands

CommandWhat it does
addSave an agent description to your library
listList your library's agent descriptions
removeRemove a description from your library and the teams that use it

Options

-h, --help

Print help (see a summary with '-h')
