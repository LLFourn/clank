clank auto

Manage this agent's auto-mode

With auto-mode on, the Stop hook keeps the session working: each time it ends a turn, clank wakes it with the next piece of work. Off, the session is driven by hand. Its role comes from the roster, not from here.

Usage

clank auto <COMMAND>

Commands

CommandWhat it does
offDrive this session by hand
onLet the Stop hook hand this session its work
statusPrint this session's auto-mode and its roster role

Options

-h, --help

Print help (see a summary with '-h')
