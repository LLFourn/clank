clank html

Render the timeline + status to a static site

Writes .clank/html/; clank html open builds and launches it in your browser.

Usage

clank html [OPTIONS] [COMMAND]

Commands

CommandWhat it does
openBuild the site and open it in your browser

Options

--repo <PATH>

Repo root. Defaults to the cwd's git toplevel

Global: every subcommand accepts it too.

--rebuild

Ignore the cached clank:last-built-sha marker and re-render every page from scratch

--quiet

Suppress the progress bar (also auto-suppressed when stderr isn't a TTY)

-h, --help

Print help (see a summary with '-h')
