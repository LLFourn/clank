clank Commands

Command reference / clank config

clank config review.require_commit_prefix

Require a [plan] or [misc] commit subject prefix

bool, default: false.

Usage

clank config review.require_commit_prefix [OPTIONS] [VALUE]

Arguments

[VALUE]

The value to write. Omit it to show the key, its value and where that value comes from

Options

--repo <PATH>

Global, inherited from clank config.

-j, --json

Global, inherited from clank config.

--global

Write to the USER-scope config (~/.clank/config.json) instead of the repo's .clank/config.json. Only affects writes; reads always show the effective merged value (repo shadows user)

Global, inherited from clank config.

-h, --help

Print help (see a summary with '-h')
