clank Commands

Command reference

clank config

Read or write clank config values

Bare, every key with its value and source. Name a key to show it, as in clank config diff.wait; give a value as well to write it, as in clank config diff.wait true (the repo's config, or yours with --global).

Usage

clank config [OPTIONS] [COMMAND]

Commands

CommandWhat it does
diff.editor.commandEditor that clank diff opens
diff.waitWhether clank diff waits for the editor
finish.autosquashSquash a plan into one commit when it finishes
hooks.blockedCommand to run when an agent blocks
recovery.blind_nudgeNudge an agent whose state clank cannot read
recovery.stall_nudgeNudge a stalled agent after its warning
recovery.stall_warnWarn when a running turn goes silent
review.adhoc_feedbackReview commits outside any plan
review.plan_feedbackReview a plan's commits
review.require_commit_prefixRequire a [plan] or [misc] commit subject prefix

Options

--repo <PATH>

Global: every subcommand accepts it too.

-j, --json

Global: every subcommand accepts it too.

--global

Write to the USER-scope config (~/.clank/config.json) instead of the repo's .clank/config.json. Only affects writes; reads always show the effective merged value (repo shadows user)

Global: every subcommand accepts it too.

-h, --help

Print help (see a summary with '-h')

Examples

clank config
clank config finish.autosquash
clank config finish.autosquash true
clank config diff.wait false --global
