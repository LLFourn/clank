clank log

Print the repo timeline: commits, reviews, github events

Chronological and newest-first, with github events interleaved by their github-side time (--no-github to leave them out, --plan to scope to one plan, --oneline / -j for compact and machine forms).

Usage

clank log [OPTIONS] [RANGE]

Arguments

[RANGE]

Commit range (git-log style). <sha> = from sha to HEAD. <from>..<to> = exclusive from, inclusive to. Omit for the last -n commits from HEAD

Options

--repo <PATH>
-j, --json
--plan <PLAN>
-n <LIMIT>

Number of commits to fold from HEAD (default 30)

Default: 30.

--oneline

Compact one-line-per-commit output

--no-github

Leave github events out of the timeline (log-timeline-github-events)

--diagnostics

Show history reconstruction diagnostics instead of the timeline. Respects the commit range, -n and --plan; --json emits typed records

-h, --help

Print help (see a summary with '-h')
