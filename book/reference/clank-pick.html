clank pick

Copy plans from another branch

Brings their commits + plan files onto the current branch; the source is never modified. Run it where the plans should land.

Usage

clank pick [OPTIONS] --from <COMMITTISH> <PLANS>...

Arguments

<PLANS>...

Plan stem(s) to copy from --from. Replayed in SOURCE order (their stacking order over there), regardless of argument order

Options

--from <COMMITTISH>

Branch (or any committish) to copy the plans FROM. Never modified — pick is a copy, not a move

Required.

--repo <PATH>

Repo root. Defaults to the cwd's git toplevel

--squash

Collapse each picked plan's commit stack into ONE commit on this branch (N plans → N commits, in source order). The commit message reuses the plan's finalize WHY when it has one

--purge

Strip the plan's .clank/ artifacts from what lands — the code is copied, the plan file / review scaffolding is not. Commits that become empty after the strip are dropped. Composes with --squash (one clean commit)

--dry-run

Print the resolved plan order and each plan's commits without picking anything (the same computation the live run applies)

-h, --help

Print help (see a summary with '-h')
