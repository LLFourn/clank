clank user-command

Type a person's signed command into an agent's pane

For the story site's Run button: the site signs one command for one agent's session, submit admits it, and the repo's monitor types !<command> into that agent's idle, empty Claude Code prompt at most once. trust-key installs the site's public key; status reports a request's state.

Usage

clank user-command <COMMAND>

Commands

CommandWhat it does
keysThe trusted keys' names and fingerprints
statusA request's state, as JSON
submitAdmit one signed request, read as a JSON envelope from stdin
trust-keyTrust a site's Ed25519 public key, read as base64 from stdin
untrust-keyStop trusting the key named --name

Options

-h, --help

Print help (see a summary with '-h')
