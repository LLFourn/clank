clank Commands

Command reference

Every clank command, generated from the command-line definitions the binary is built from. Each page says what that command's --help says.

Multi-agent peer review around plans

Usage

clank <COMMAND>

Commands

CommandWhat it does
agentManage this repo's agent roster
asBind this session to a roster label
attendDeclare background work clank cannot observe, such as a subagent
autoManage this agent's auto-mode
blockQuestions only the human can answer
configRead or write clank config values
diffOpen a plan or commit-range diff in your editor
doctorCheck the clank setup across repo, user, and session
eventsThe event inbox: what your wake sources delivered
exportDump the repo's roster config as JSON
feedbackRead or write review feedback
finishFinalize a plan into finished/
forkFork the team into a linked worktree
htmlRender the timeline + status to a static site
initScaffold .clank/ in a repo
logPrint the repo timeline: commits, reviews, github events
nudgeInterrupt an agent and type a message into its terminal
openOpen the team workspace in zellij
pickCopy plans from another branch
purgeStrip a plan's .clank/ artifacts from history
queueManage the plan queue
remoteSwitch this repo's remote on or off through its clank tui
rereviewRe-open review on a plan's latest reviewable commit
runRun a command under clank, so it knows when the work ends
sendPut a message in an agent's inbox
setupInstall skills and hooks for Claude, Codex, Grok and OpenCode
stashSet a plan's commits aside and restore them later
statusShow the repo's clank state
teamYour saved teams and agent descriptions, shared across repos
tuiThe full-screen pane for driving a running team
unfinishMove a finalized plan back to active
user-commandType a person's signed command into an agent's pane
waitBlock until this agent has actionable work

Options

-h, --help

Print help

-V, --version

Print version
