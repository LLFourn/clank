clank setup

Install skills and hooks for Claude, Codex, Grok and OpenCode

User-scope assets in ~/.claude, ~/.codex, ~/.grok and ~/.config/opencode: the role-split skills, Claude's and Codex's lifecycle hooks, Grok's native hook adapter and the OpenCode plugin. Re-run after upgrading, since a new release can add a hook; --force refreshes edited skills.

Usage

clank setup [OPTIONS]

Options

--grok-agent <AGENT>

Install Grok assets for this repo's configured Grok agent/profile

--repo <PATH>

Repo used by --grok-agent. Defaults to the current repo

--force

Overwrite skill/command files even if they've drifted from the embedded content (e.g. user manually edited). Hook entries in settings.json / hooks.json are always merged regardless of this flag

--dry-run

Show what would change without writing anything

-h, --help

Print help (see a summary with '-h')
