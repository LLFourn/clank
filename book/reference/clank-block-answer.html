clank block answer

Answer a repository question

Usage

clank block answer [OPTIONS] <NAME>

Arguments

<NAME>

Block name to answer

Options

-m <MSG>

Answer message. -m - reads it from stdin

--nudge

Type the answer into the agent's terminal as your own message, the way clank nudge does, and record it only once it was submitted. The only way to answer a permission block. If the outcome is unknown the block stays unresolved, and nothing is resent

--resend

With --nudge: replace an outstanding nudge whose text you know did not arrive, or whose duplicate you accept, and type it again

--delivered

Settle an outstanding nudge whose text you saw arrive: record it as the answer, typing nothing

--override-permission-classifier

Required to answer a permission block (with --nudge, --resend or --delivered): it lifts a refusal the agent's permission classifier made, so it must be run by a person. The name is a hint to that classifier, which refuses a command announcing it bypasses permission checks; it is not enforcement, and an agent running without the classifier can still pass it. Ordinary blocks ignore it

--repo <PATH>
-h, --help

Print help
