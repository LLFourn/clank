clank queue

Manage the plan queue

Plans wait here in priority order until the master starts them. A queued plan's body is written first as .clank/drafts/<name>.md. Removing an entry deletes it; unqueueing returns it to drafts.

Usage

clank queue [OPTIONS] [COMMAND]

Commands

CommandWhat it does
addQueue a drafted plan
promotePromote a queued item to an active plan
removeRemove an item from the queue
reprioritiseChange a queued item's priority (renames its NNN- prefix)
unqueueMove a queued plan back to drafts

Options

--repo <PATH>

Global: every subcommand accepts it too.

-h, --help

Print help (see a summary with '-h')
