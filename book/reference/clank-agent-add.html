clank Commands

Command reference / clank agent

clank agent add

Put an agent on this repo's roster, with its review tier

By name, the agent is copied from your library (clank team agent add puts one there); with --tool, it is defined here. --review sets the tier; without it the agent becomes master on a roster that has none, and a commit reviewer otherwise. In a repo with no .clank/config.json it first sets up what clank init would (.clank/.gitignore, the post-rewrite hook) but imports no team.

Usage

clank agent add [OPTIONS] <AGENT> [-- <TOOL ARGS>...]

Arguments

<AGENT>

Agent label to add

[TOOL ARGS]...

The tool's own arguments, after --, exactly as you would type them to the tool: clank agent add web --tool codex -- --no-daemon -c key=value. Keep them to the few flags that select a configuration; MCP servers and feature switches belong in the tool's own config file or a per-agent home (--env)

Options

--tool <TOOL>

Tool this agent runs, to define it here. Omit it to add <label> by name, copied from your library (clank team agent add)

Possible values:

  • claude
  • codex
  • grok
  • opencode: One word, like the binary (clap would kebab-case the variant)
--review <REVIEW>

Tier for the new roster entry: commit, plan, final, gate, or standby. Omitted, the agent becomes master on a roster that has none, and commit otherwise

Possible values:

  • commit
  • plan
  • final
  • gate
  • standby: Reviews nothing; woken for everything else
--cmd <EXECUTABLE>

The executable clank agent start runs, instead of the tool's own name

--env <KEY=VAL>

An environment variable for the agent's process, KEY=VAL; repeatable. It wins over the inherited environment. A per-agent tool home goes here: --env CODEX_HOME=~/.codex-browser

May be repeated.

--initial-prompt <STRING>

Initial prompt passed to the resumed tool as a trailing positional. Pass "" to explicitly disable the prompt (escape hatch when auto_mode == On but you don't want the default Session resumed. prompt). Unset = follow auto_mode default

--repo <PATH>

Repo root. Defaults to the cwd's git toplevel

-h, --help

Print help (see a summary with '-h')

Examples

# a codex reviewer that reviews every commit
clank agent add codex --tool codex --review commit
# the tool's own arguments go after --
clank agent add web --tool codex -- --no-daemon -c model=o3
# copy an agent from your library by name
clank agent add opus
