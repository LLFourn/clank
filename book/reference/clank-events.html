clank events

The event inbox: what your wake sources delivered

Every event a wait ingests (GitHub activity, messages, scheduled events) lands here and keeps waking its agent until it is acknowledged. Listing and showing give metadata only. Reading returns the content, which is external and untrusted, and records that it was delivered to you.

Usage

clank events <COMMAND>

Commands

CommandWhat it does
ackMark events handled so they stop waking you
listList event metadata without reading content (unhandled by default)
readRead an event's content and record delivery to your bound agent
replyReply to an event without acknowledging it
showInspect one event's metadata without reading content
watchList, add and remove the agent's standing wake sources

Options

-h, --help

Print help (see a summary with '-h')
