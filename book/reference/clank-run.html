clank Commands

Command reference

clank run

Run a command under clank, so it knows when the work ends

Start this in the background instead of the bare command: clank run --desc "test run" -- cargo test. Clank registers the run with the monitor, beside anything else you attend, then BECOMES the command — same pid, same stdio, same exit status. When that process is gone you are woken once; its output and exit status are wherever you launched it. --expect 30m says how long it should take; past that you are checked in on once, and nothing is cancelled. With no monitor to take the registration the command is refused and does not run.

Usage

clank run [OPTIONS] --desc <TEXT> <CMD>...

Arguments

<CMD>...

The command to run, after --

Options

--desc <TEXT>

TWO WORDS for what you are waiting on — --desc "test run". What clank tui shows, and the name clank attend renews or clears the run by

Required.

--expect <DURATION>

How long you expect this to take (30s, 5m, 1h; default 5m). Not a timeout — nothing is cancelled. If the work is still running past it you are woken once with a check-in, so a hang cannot hold you asleep for hours

Default: 5m.

--author <AGENT>

Agent label. Resolved from env when omitted

--repo <PATH>
-h, --help

Print help (see a summary with '-h')
