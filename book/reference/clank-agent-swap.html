Command reference / clank agent

clank agent swap

Replace one reviewer with another in the same role

One config write, so the role is never vacant and the gate never briefly expects fewer reviewers. The incoming agent is copied from your library and must not already be on the roster. The master is not swapped this way (use agent make-master).

Usage

clank agent swap [OPTIONS] <OUT> <IN>

Arguments

<OUT>

Reviewer to swap OUT. Must be on the roster

<IN>

Reviewer to swap IN. Must NOT already be on the roster; its description is copied from the user-scope library

Options

--repo <PATH>

Repo root. Defaults to the cwd's git toplevel

-h, --help

Print help (see a summary with '-h')
