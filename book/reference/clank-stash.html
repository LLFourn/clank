Command reference

clank stash

Set a plan's commits aside and restore them later

Bare clank stash [PLAN] pushes, as git stash does: the one in-flight plan, or the named one. Its commits are kept on a protective ref and taken off the branch, so another plan can run. Where only one plan is stashed, commands that act on a stash take it without a name. --to-queue re-queues the plan body for a later attempt instead.

Usage

clank stash [OPTIONS] [PLAN] [COMMAND]

Commands

CommandWhat it does
dropPermanently discard a plan's stashed commits + record
listList the stashed plans
popBring a stashed plan back onto the branch
pushSet a plan aside, the same as bare clank stash
showPrint a stashed plan's body (from its protective ref) + commits

Arguments

[PLAN]

Plan stem to stash (same parsing as clank purge). Optional when the repo has exactly one in-flight active plan

Options

--repo <PATH>

Repo root. Defaults to the cwd's git toplevel

--for <PLAN>

Record that this plan is waiting on another; clank status nudges to pop once that plan finishes

--to-queue

Also save the plan body back to the queue for re-attempt from scratch

--priority <N>

Queue priority for --to-queue (default 500)

--dry-run

Print the plan without changing anything

-h, --help

Print help (see a summary with '-h')

Examples

# set the active plan aside, run another, then bring it back
clank stash
clank stash pop
# give the plan up for now, keeping its body in the queue
clank stash --to-queue
