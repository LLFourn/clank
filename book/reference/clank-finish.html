clank Commands

Command reference

clank finish

Finalize a plan into finished/

Runs when the gate says FINISHED; -m is required (what changed, then why). With finish.autosquash the plan's commits collapse into one.

Usage

clank finish [OPTIONS] [PLAN]

Arguments

[PLAN]

Plan to finalize. Accepts <repo>/<stem>.md or just <stem>. Optional when the cwd-repo has exactly one in-flight active plan

Options

--repo <PATH>

Repo root. Defaults to the cwd's git toplevel

-m, --message <MESSAGE>

REQUIRED (when authoring the finish commit): the whole plan's commit message — a brief WHAT subject and a WHY body, written as if the whole plan were one commit. It becomes the plan's squash summary. A bare finish / subject-only message is rejected. Repeatable, git-style: each -m becomes a paragraph (e.g. -m "<subject>" -m "<why>"), and -m - reads one paragraph from stdin

May be repeated.

--purge

After finalize, strip the plan's .clank/ artifacts from history (runs the rewrite engine on the just-extended range). The finalize snapshot is included in the strip

--squash <MSG>

After finalize, collapse the plan's commits into one with the supplied message. Commits in the range that are not the plan's (adhoc, or another plan's) move ahead of it, each keeping its own message and author; only one that will not apply there refuses the squash, and then nothing is rewritten. Combine with --purge to also strip the plan's .clank/ artifacts

--no-squash

Opt OUT of finish.autosquash for this one finish — keep the plan's individual commits (e.g. a bisectable refactor). No effect when autosquash is off or --squash is given explicitly

--into-branch <NAME>

Write the rewritten history to a fresh branch instead of in-place. Only meaningful with --purge/--squash

--dry-run

Preview any history edit this finish would perform, without creating commits or moving refs: the --purge/--squash rewrite plan, or the reword plan for a bare -m on an already-finished plan (the same computation the live run applies). Ignored on a plain fresh finish (no history rewrite happens there)

--force

Finalize even when the review gate hasn't said FINISHED (unreviewed / continued / changes-requested / pending gate tier). Bypasses ONLY the review-gate readiness: messages stay mandatory, autosquash still applies, and safety refusals (dirty plan file, missing plan file, open human block, no reviewable commit) stand

--no-cache

Skip the on-disk state cache: don't read it, don't write it

-h, --help

Print help (see a summary with '-h')

Examples

# finish the one active plan: what changed, then why
clank finish -m "Parse errors name the line" -m "Users could not find the typo"
