Command reference

clank init

Scaffold .clank/ in a repo

Creates plans/ and the managed .gitignore, and installs the post-rewrite hook. --team <name> seeds the roster from a saved template.

Usage

clank init [OPTIONS]

Options

--repo <PATH>

Repo root. Defaults to the cwd's git toplevel

--force

With --team <name>: replace an existing VALID repo roster. Without it, --team refuses to clobber a configured repo roster (run clank team save <name> first to keep local edits). Bare clank init ignores this flag

--team <NAME>

Seed this repo's roster from a user-scope team template. Copies the named template's roster + referenced agent definitions into <repo>/.clank/config.json. The template must exist in ~/.clank/config.json#/teams. When omitted, a repo without a roster is seeded from your team named default if you have one, and otherwise starts with no roster — build one with clank agent add (the first agent becomes master). An existing roster is never replaced by a bare init

-h, --help

Print help (see a summary with '-h')

Examples

# start using clank in the current repo
clank init
# and seed its roster from a saved team
clank init --team review-pair
