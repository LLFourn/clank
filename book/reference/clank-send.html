clank send

Put a message in an agent's inbox

Addressed by repo (--repo, default the current one) and label (--to), or --master for whoever that repo's roster names master. The message wakes its agent until it is handled.

Usage

clank send [OPTIONS] <--to <AGENT>|--master> <--message <TEXT>|--file <PATH>>

Options

--reply-to <AGENT>

Require a reply to this concrete agent in the invoking repo

--reply-repo <PATH>

Reply destination repo; defaults to the invoking repo, independently of --repo

--interrupt

Request best-effort interruption; the event remains pending if unavailable

--repo <PATH>

The recipient's repo. Defaults to the cwd's git toplevel

--to <AGENT>

The agent to send to, by its label on that repo's roster

--master

Send to whoever that repo's roster names master

-m, --message <TEXT>

The message. Repeat for paragraphs, as with git commit -m; -m - reads one paragraph from stdin

May be repeated.

-F, --file <PATH>

Read the message from a file; - reads stdin

-h, --help

Print help (see a summary with '-h')

Examples

clank send --master -m "CI is red on main"
clank send --to codex --repo ../other -m "Your review is waiting"
