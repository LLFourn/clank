clank block

Questions only the human can answer

An agent asks when it needs a decision it must not make itself, and waits; the human's answer wakes it.

Usage

clank block <COMMAND>

Commands

CommandWhat it does
answerAnswer a repository question
askAsk the human a question, and wait for the answer
cleanTidy away settled repository questions and leftover answer files
listRead repository questions and answers, including received decisions

Options

-h, --help

Print help (see a summary with '-h')
