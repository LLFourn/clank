Command reference

clank purge

Strip a plan's .clank/ artifacts from history

--drop removes the plan entirely (commits included).

Usage

clank purge [OPTIONS] [PLAN]

Arguments

[PLAN]

Plan to purge. Accepts <repo>/<stem>.md or just <stem>. Omit to infer the single active in-flight plan, or pass --all to strip every .clank/ path. Mutually exclusive with --all

Options

--all

Strip EVERY .clank/ path from history (plan files, finalize snapshots, AND non-plan Clank metadata like .clank/.gitignore and .clank/queue/*). Cannot be combined with a plan argument

--repo <PATH>

Repo root. Defaults to the cwd's git toplevel

--into-branch <NAME>

Write the rewritten chain to a fresh branch instead of rewriting the current branch in place. Safer — the operator can inspect / cherry-pick / diff before deciding what to do with it. Refuses if <name> already exists

--dry-run

Print the planned rewrite and exit 0 without moving any refs or touching the index or worktree. With --drop it also names the conflict a live run would stop at

--squash <MSG>

Collapse the plan-attributed range into a single commit with the supplied message, moving commits that are not the plan's ahead of it. Not pipeable to git rebase — see --dry-run output for the planned target tree

--amend

Amend HEAD instead of building a new chain. HEAD must already be a finalize commit (paths under .clank/finished/ and .clank/plans/ matching the plan stem, or under .clank/finished/ for --all)

--no-cache

Skip the on-disk state cache: don't read it, don't write it

--drop

Drop EVERY commit attributed to the plan, including the implementation code — not just .clank/ artifacts. The plan AND its work both vanish from history, wherever they are in it; every other commit after them is kept, in order. If one of those no longer applies without the plan, the drop stops in a git rebase for you to resolve and --continue (or --abort). Does NOT save the plan body — use clank stash push --to-queue if you want to re-queue it for another attempt. Mutually exclusive with --all, --squash, and --amend

-h, --help

Print help (see a summary with '-h')
