clank nudge

Interrupt an agent and type a message into its terminal

The escape hatch for when clank send cannot be delivered — a wedged hook, a stale binding, a wake that never fires. It reads no inbox and no session binding, and fails rather than guess which pane it meant. Unlike send, it leaves nothing waiting to be acknowledged; each attempt and its outcome is added to the agent's nudge history.

Usage

clank nudge [OPTIONS] <--to <AGENT>|--master> <--message <TEXT>|--file <PATH>>

Options

--repo <PATH>

The recipient's repo. Defaults to the cwd's git toplevel

--to <AGENT>

The agent to nudge, by its label on that repo's roster

--master

Nudge whoever that repo's roster names master

-m, --message <TEXT>

The message. Repeat for paragraphs, as with git commit -m; -m - reads one paragraph from stdin

May be repeated.

-F, --file <PATH>

Read the message from a file; - reads stdin

-h, --help

Print help (see a summary with '-h')
