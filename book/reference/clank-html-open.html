clank html open

Build the site and open it in your browser

Opens the index, or one plan's page when a plan is named.

Usage

clank html open [OPTIONS] [PLAN]

Arguments

[PLAN]

Plan name. When supplied, the browser opens plan/<stem>.html instead of index.html. Resolved against active plans first, then finished — same shape as clank diff <plan>

Options

--commit <SHA>

Commit sha (short or full). When supplied, the browser opens commit/<full_sha>.html. Mutually exclusive with a plan name

--queue <NAME>

Queued plan name. When supplied, the browser opens queue/<name>.html. Mutually exclusive with a plan name or commit

--stash <NAME>

Stashed plan name. When supplied, the browser opens stash/<name>.html. Mutually exclusive with the other targets

--print

Print the resolved target path on stdout and exit without launching a browser. Mirrors --print on clank agent start, clank diff, clank open

--repo <PATH>

Repo root. Defaults to the cwd's git toplevel

Global, inherited from clank html.

-h, --help

Print help (see a summary with '-h')
