Command reference / clank stash

clank stash push

Set a plan aside, the same as bare clank stash

Its commits are kept restorable on a protective ref and taken off the branch.

Usage

clank stash push [OPTIONS] [PLAN]

Arguments

[PLAN]

Plan stem to stash (same parsing as clank purge). Optional when the repo has exactly one in-flight active plan

Options

--repo <PATH>

Repo root. Defaults to the cwd's git toplevel

--for <PLAN>

Record that this plan is waiting on another; clank status nudges to pop once that plan finishes

--to-queue

Also save the plan body back to the queue for re-attempt from scratch

--priority <N>

Queue priority for --to-queue (default 500)

--dry-run

Print the plan without changing anything

-h, --help

Print help (see a summary with '-h')
