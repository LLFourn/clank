Reference

The flags live with the commands. This book does not copy them, because a copy is the first thing to go stale.

clank --help
clank fork create --help

Every command and subcommand has its own --help, which comes from the binary you are running and so is always current. The README keeps a command reference table and the long-form detail on wake sources, replies and interruption.

Config keys

clank config on its own lists every key with its value and where the value came from. Give a key and a value, as in clank config diff.wait true, to write the repo’s config. Add --global to write yours.

finish.autosquash
Collapse a plan into one commit when it finishes. It rewrites the current branch in place, so it is off by default.
review.plan_feedback
Require review of a plan’s commits. On by default.
review.adhoc_feedback
Also review commits outside any plan. Off by default.
review.require_commit_prefix
Require a [plan] or [misc] prefix on every commit subject.
hooks.blocked
A command to run when an agent raises a block.
diff.editor.command, diff.wait
The editor clank diff opens, and whether it waits for it.
recovery.blind_nudge
Nudge an agent that owes work when clank cannot read its state. Off by default, which leaves such an agent to a person.

When a message cannot get through

clank send is the normal route, and --interrupt asks for the recipient’s turn to be interrupted as well. clank nudge is the recovery route for a wedged hook, a stale binding, or a wake that never fires. It interrupts the agent’s pane and types the message straight into its terminal, reading no inbox and no binding. Nothing waits to be acknowledged, but every attempt is kept in the agent’s nudge history.
